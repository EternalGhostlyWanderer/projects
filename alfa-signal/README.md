# Альфа Сигнал

> **Команда «Поколение Альфа»** · кейс «Альфа Хак — Новостная аналитика для принятия бизнес-решений»
>
> **Версия для проверки:** тег `submission-2026-10-26` в ветке `main`
> (код и данные — коммит [`b2a0c6d`](https://github.com/fvdzg/alfa-signal/commit/b2a0c6d); дальше менялся только README).
>
> **Ключ LLM:** ключ организаторов истёк вместе с хакатоном. Сервис работает с любым
> OpenAI-совместимым провайдером. Бесплатные варианты: OpenRouter (модели `:free`), Groq, Google Gemini, Mistral
> или локальная Ollama без ключа. Укажите `LLM_PROVIDER` и `LLM_API_KEY` (для Docker — в корневом `.env`,
> для локального запуска — в `backend/.env`). Подробнее: [docs/free-llm-providers.md](docs/free-llm-providers.md).
> Без ключа сервис работает на готовых данных: ленты, 35 готовых разборов агента, позиция Альфа-Банка.
> С ключом дополнительно доступны живой разбор любой новости, вопросы к разбору и предварительный анализ.

**Альфа Сигнал** — персональная новостная аналитика для руководителей крупного бизнеса внутри интернет-банка
«Альфа-Бизнес». Сервис отбирает из потока новостей то, что касается конкретной компании, и объясняет, чем
это грозит или что даёт. Для каждого события он показывает:
- причинную цепочку;
- риски и возможности;
- позицию аналитиков Альфа-Банка;
- следующие шаги.

Каждое утверждение ссылается на проверяемый источник и помечено: факт, аналитика банка, вывод модели или
гипотеза.

Финансовый директор, главный бухгалтер и собственник одной компании видят разную ленту и разные акценты в
разборе: рекомендации персональны не только для компании, но и для человека.

## Быстрый старт для проверки (5 минут, ключ LLM не нужен)

```bash
git clone https://github.com/fvdzg/alfa-signal.git
cd alfa-signal
cp .env.example .env          # Windows: copy .env.example .env
docker compose up --build -d
```

Откройте **http://localhost:8080** и войдите:

| Логин | Пароль | Кто это |
|---|---|---|
| `demo` | `alfa-signal` | финансовый директор |
| `buh` | `alfa-signal` | главный бухгалтер |
| `owner` | `alfa-signal` | собственник |

Без ключа всё работает на готовых данных из репозитория:
- **шесть синтетических компаний** из разных отраслей: металлоконструкции, розница, грузоперевозки,
  строительство, зерно, металлургия;
- **около 70 новостей:** официальные источники (Банк России, Мосбиржа), деловые издания и пул заготовленных
  демонстрационных новостей;
- **готовые разборы агента** с источниками, журналом шагов и ролевыми блоками;
- **индекс аналитики Альфа-Банка:** 9 документов, 251 фрагмент, 40 прогнозов. Позиция банка находится
  без PDF и распознавания.

Если указать `LLM_API_KEY` в `.env`, новые разборы делаются вживую и подтягиваются поверх готовых.

Чистый перезапуск: `docker compose down -v && docker compose up --build -d`.

## Что посмотреть

1. **Лента под компанию.** Выберите SYN_001 (металлоконструкции, кредиты, торговля с Китаем), затем SYN_005
   (зерно, экспорт в Турцию). Ленты разные, и у каждой карточки есть «Почему в ленте» — объяснимый балл
   по признакам компании.
2. **Лента под роль.** Выйдите и войдите под `buh`: у бухгалтера выше налоги и регулирование, у финдиректора —
   ставка, курс и стоимость долга.
3. **Разбор события.** Откройте карточку с меткой «Проверено автоматически»:
   - причинная цепочка «событие → канал → эффект»;
   - риски и возможности;
   - позиция Альфа-Банка с цитатой из документа;
   - следующие шаги и блок для вашей роли.
4. **Ход анализа.** Внизу разбора видны шаги агента: план, вызовы инструментов, проверка, исправление.
5. **Честность.** Где подтверждённого тезиса банка нет, сервис так и пишет, а не придумывает. Разбор по одному
   заголовку получает статус «частично». Устаревшая аналитика помечается.
6. **Своя новость.** Вставьте ссылку или текст новости, которой нет в ленте. Нужен ключ LLM.
7. **Вопрос к разбору:** «Что если ставка снизится на 1 п.п. при долге 500 млн руб.?» Нужен ключ LLM.
8. **Прочитанное.** Открытые карточки бледнеют, как прочитанные сообщения.

## Возможности

| | |
|---|---|
| **Персональная лента** | Объяснимый балл 0–100 по отрасли, финансовым каналам (кредиты, лизинг, депозиты, ВЭД), странам торговли, контрагентам по платежам, связанным компаниям и задачам роли. Модель для ленты не нужна. |
| **Агент-аналитик** | План → инструменты (профиль, связи, релевантность, аналитика банка, официальные курсы и ставка ЦБ, прогнозы банка) → разбор → автоматическая проверка → исправление → итог. |
| **Аналитика Альфа-Банка** | Поиск BM25 по распознанным PDF, прогнозы из таблиц, отслеживание пересмотров прогнозов и устаревших документов. |
| **Проверка выводов** | Числа без источника, факты без доказательств, вывод под видом факта, неиспользованная аналитика банка, расхождение цифр между изданиями. Статусы: проверено / частично / устарело / противоречие. |
| **Новости** | RSS деловых изданий и информагентств (РБК, Коммерсантъ, Ведомости, Интерфакс, ТАСС), API Банка России и Мосбиржи, по ссылке или вставленным текстом. Склейка публикаций об одном событии, сюжеты, подтверждение фактов несколькими изданиями. |
| **Фильтры шума** | Новости не про бизнес, кликбейт, заявления без новой меры, онлайн-трансляции. Учитывается надёжность источника. |
| **Свежесть** | Свежее выше. Старое, но очень важное событие не опускается вниз, если новых новостей не было. |
| **Обновление** | Каждые 30 минут, пока в сервисе работают; при входе, если данные старше 30 минут; кнопкой. Верхние события ленты разбираются заранее, в фоне. |
| **Роли** | Финдиректор, бухгалтер, собственник и другие: своя лента, свой блок в разборе, свои скрытые события и история вопросов. |
| **Данные клиента** | Клиент дополняет профиль в интерфейсе (выручка, долг, контрагенты, важные темы). Из документа клиента поля извлекаются через API (`/user-data/extract`). Каждое поле помечено источником. |
| **Сводка** | Главные события компании за день или неделю — блок над лентой. |

## Как это работает

```
Новости: RSS · Банк России · Мосбиржа · ссылка · текст
        │  фильтры шума, склейка дублей, подтверждение фактов
        ▼
Событие: тип, каналы влияния, отрасли, страны (ключевые слова или LLM)
        │
Компания: профиль, продукты банка, ВЭД, платежи, группа, положение в отрасли
        │
        ▼
Объяснимый скоринг 0–100 под компанию и роль → лента
        │
        ▼
Агент: план → инструменты → разбор → проверка → исправление
        ├─ профиль и связи компании
        ├─ официальные данные ЦБ (ставка, курсы)
        └─ аналитика Альфа-Банка (поиск, прогнозы, пересмотры)
        │
        ▼
Разбор: каждое утверждение — FACT / BANK_ANALYSIS / AI_INFERENCE / HYPOTHESIS
со ссылками на доказательства + журнал шагов агента + блок для роли
```

| Часть | Технологии |
|---|---|
| Backend | Python 3.11+, FastAPI, Pydantic v2, SQLite |
| LLM | разрешённые модели через шлюз организаторов: анализ — `qwen/qwen3.6-35b-a3b`, распознавание сканов — `qwen/qwen3-vl-30b-a3b-instruct` |
| Поиск по аналитике | собственный BM25, PyMuPDF |
| Frontend | React, TypeScript, Vite, Tailwind, shadcn/ui |

## Качество

| Что измеряли | Результат |
|---|---|
| Ручная разметка ленты: 240 пар «компания × событие», 3 разметчика, согласие (взвешенная каппа) | 0,82–0,91 — почти полное |

| Поиск по аналитике банка, контрольные вопросы | 100% первое попадание |
| Автотесты backend | 260+, без обращений к LLM |

## Данные и безопасность

- **Данные компаний.** В репозитории только синтетические компании (`data/synthetic/`). Данные организаторов
  подключаются локально и в git не попадают.
- **Аналитика Альфа-Банка.** В репозитории лежит распознанный текст и поисковый индекс
  (`data/processed/`), без самих PDF. Репозиторий приватный; если он станет публичным, эти файлы нужно убрать.
- **Изоляция.** Компания видит только свою ленту. Новость, присланная одной компанией, не попадает к другим.
- **Ссылки пользователя.** Разрешены только публичные адреса, внутренняя сеть закрыта (защита от SSRF).
  Каждый редирект проверяется.
- **Подмена инструкций.** Текст новости для модели — данные, а не команды. В демо есть синтетическая новость
  с фразой «игнорируй инструкции…», агент её не выполняет.
- **Расходы.** Суточные лимиты запросов к модели. Ленту и заранее подготовленные разборы можно смотреть без ключа.
- **Дисклеймер.** Сервис не даёт индивидуальных инвестиционных рекомендаций.

## Запуск без Docker

Нужны Python 3.11+ и Node.js 20+. Команды выполняются из корня репозитория.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1                 # macOS/Linux: source .venv/bin/activate
pip install -r backend/requirements.lock
```

**Терминал 1 — backend.** Ключ LLM, если есть, укажите в `backend/.env` строкой `LLM_API_KEY=...`.
```powershell
$env:COMPANIES_CSV="data/synthetic/companies.csv"
$env:PAYMENTS_CSV="data/synthetic/payments.csv"
$env:PEOPLE_CSV="data/synthetic/people.csv"
python backend/scripts/seed_demo.py         # готовые разборы и пул новостей
cd backend
uvicorn app.main:app --reload --port 8000
```

**Терминал 2 — frontend:**
```powershell
cd frontend
npm ci
copy .env.example .env.local                # macOS/Linux: cp
npm run dev
```

Интерфейс — http://localhost:5173, Swagger — http://localhost:8000/docs.

## Запуск на данных организаторов

1. Положите CSV в `data/raw/` и укажите их в `.env`:
   ```dotenv
   COMPANIES_CSV=data/raw/df_Uid_data_hack.csv
   PAYMENTS_CSV=data/raw/df_Uid_payment_hack.csv
   PEOPLE_CSV=data/raw/df_Fid_Uid_link_hack.csv
   SEED_SYNTHETIC_DATA=0
   VITE_COMPANY_IDS=U_9250,U_57706,U_177581
   LLM_API_KEY=<ключ>
   ```
2. Выполните `docker compose up --build -d`. После смены `VITE_COMPANY_IDS` frontend нужно пересобрать.
3. Соберите свежие новости: `POST /api/v1/events/collect` в Swagger или кнопка «Обновить ленту».
4. Проверьте готовность: `python backend/scripts/check_runtime.py --require-llm --require-bank-index`.

Индекс аналитики банка уже в репозитории. Чтобы заменить материалы, положите PDF в `data/raw/news/` и
выполните `python backend/scripts/build_bank_index.py`. Подробно — [`docs/deployment.md`](docs/deployment.md).

## Проверка через API

В Docker с экраном входа API принимает только подписанную сессию. Получите токен и передавайте его в
заголовке `Authorization: Bearer <access_token>`:
```bash
curl -s -X POST http://localhost:8000/api/v1/auth/login -H "Content-Type: application/json" \
  -d '{"login": "demo", "password": "alfa-signal"}'
```
При локальном запуске без Docker вход не требуется.

| Шаг | Запрос |
|---|---|
| Ленты двух компаний различаются | `GET /api/v1/feed?company_id=SYN_001` и `?company_id=SYN_002` |
| Лента под роль | `GET /api/v1/feed?company_id=SYN_001&role=accountant` |
| Разбор события | `POST /api/v1/insights/analyze` `{"company_id": "SYN_001", "event_id": "..."}` |
| Журнал агента | `GET /api/v1/insights/{insight_id}/trace` |
| Блок для роли | `GET /api/v1/insights/{insight_id}/role-view?role=owner` |
| Своя новость | `POST /api/v1/insights/analyze` `{"company_id": "SYN_001", "title": "...", "text": "..."}` |
| Вопрос к разбору | `POST /api/v1/insights/{insight_id}/ask` `{"question": "..."}` |
| Состояние сервиса | `GET /api/v1/system/status`: модель, индекс банка, источники, планировщик |

## Основные переменные окружения

| Переменная | Назначение |
|---|---|
| `LLM_PROVIDER` | пресет провайдера: `openrouter`, `groq`, `gemini`, `mistral`, `ollama`, `hackathon` ([docs/free-llm-providers.md](docs/free-llm-providers.md)) |
| `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL` | ключ провайдера; адрес и модель, если не подходят значения из пресета |
| `LLM_FALLBACKS`, `GROQ_API_KEY`, `OPENROUTER_API_KEY` | запасные нейросети по порядку, если основная не ответила ([docs/free-llm-providers.md](docs/free-llm-providers.md#запасные-нейросети-llm_fallbacks)) |
| `LLM_DAILY_REQUEST_LIMIT`, `LLM_DAILY_COST_LIMIT` | суточные лимиты |
| `NEWS_RSS_URLS_FOREIGN`, `NEWS_TRANSLATE_BATCHES` | иностранные издания на английском с переводом на русский ([docs/news-collection.md](docs/news-collection.md#иностранные-издания-английский)) |
| `NEWS_FETCH_FULL_TEXT` | `1` — агент загружает полный текст статьи, если в ленте только анонс |
| `AGENT_LLM_PLAN`, `ROLE_VIEW_LLM` | `0` — план агента и ролевой блок по правилам, меньше запросов к LLM |
| `AUTH_STRICT`, `AUTH_USERS`, `DEMO_AUTH_SECRET` | вход на внешнем сервере: обязателен для всего API, пароли хешем ([docs/deployment.md](docs/deployment.md#внешний-сервер-vps-в-европе)) |
| `COMPANIES_CSV`, `PAYMENTS_CSV`, `PEOPLE_CSV` | данные компаний, платежей и связей |
| `SEED_SYNTHETIC_DATA` | загрузить демо-снимок и пул новостей в чистую базу (1 по умолчанию) |
| `NEWS_COLLECT_MODE`, `NEWS_COLLECT_INTERVAL_MIN` | сбор новостей: `active` — пока работают пользователи, `always` — всегда |
| `PREANALYZE_ACTIVE`, `PREANALYZE_PER_COMPANY`, `PREANALYZE_DAILY_LIMIT` | заранее разбирать верхние события ленты (включено, 10 на компанию, 150 в сутки) |
| `API_REQUIRE_COMPANY_SCOPE` | строгая изоляция компаний для внешнего стенда |
| `VITE_DEMO_AUTH`, `DEMO_AUTH_REQUIRED`, `DEMO_AUTH_SECRET` | экран входа и подписанные сессии |

Полный список — `.env.example`.

## Что настоящее, а что смоделировано

- **Настоящее:**
  - анализ разрешёнными моделями, агент и автоматическая проверка выводов;
  - поиск по аналитике Альфа-Банка;
  - сбор новостей из RSS, API Банка России и Мосбиржи, по ссылке;
  - скоринг, проверенный ручной разметкой.
- **Смоделировано:**
  - интерфейс интернет-банка и вход (в банке его заменит SSO);
  - синтетические компании;
  - часть демонстрационных новостей — они помечены как демонстрационные.
