# Изменения во фронтенде (участник 3)

Сделано участником 1 в ветке `ai/agent-api`: фронтенд подключён к backend API. Вёрстка, стили и
компоненты сохранены; заменены источники данных и захардкоженные тексты карточки. Демо-режим работает
как раньше (`VITE_USE_DEMO=1`). Проверено: `npm run check` и `npm run build` проходят; сценарий
«лента → клик → анализ → карточка → ход анализа → вопрос → отзыв» пройден в браузере (Playwright),
ошибок в консоли нет.

## Как запустить
```powershell
# backend (см. README.md): uvicorn на http://localhost:8000
cd frontend
copy .env.example .env.local     # при необходимости поправить VITE_COMPANY_IDS
npm ci
npm run dev                      # http://localhost:5173 — запросы /api проксируются на :8000
```

## Новые файлы
| Файл | Что делает |
|---|---|
| `src/features/insights/api.ts` | типы ответов backend (snake_case) и `apiRequest` с понятными сообщениями для 429/502/503 |
| `src/features/insights/apiInsightsAdapter.ts` | приводит ответы API к существующим типам `BusinessInsight`, `CompanyProfile`, `InsightsWorkspace`; русские подписи каналов, продуктов, типов событий |
| `src/features/insights/dataSource.ts` | единая точка: API или демо (`VITE_USE_DEMO`). Страницы импортируют только его |
| `src/components/insights/AnalysisTrace.tsx` | раскрывающийся блок «Ход анализа» — шаги агента из `/insights/{id}/trace` |
| `frontend/.env.example` | `VITE_USE_DEMO`, `VITE_COMPANY_IDS`, `VITE_API_URL` |

## Изменённые файлы
- **`model.ts`** — только необязательные поля: `eventId`, `mechanismSteps`, `bankView`, `qualityStatus`,
  `qualityIssues`, `traceId`, `isPending`; новые типы `ChatMessage`, `AnalysisTrace`, `ChecklistItem`;
  в `InsightsWorkspace` — необязательный `checklist`. Демо-данные не менялись.
- **`queries.ts`** — ключи `companies`, `trace`, `chat`.
- **`vite.config.ts`** — прокси `/api` → `http://localhost:8000` (адрес — `VITE_PROXY_TARGET`).
- **`InsightsPage.tsx`**:
  - список компаний и лента — из API (`fetchCompanies`, `fetchInsightsWorkspace`);
  - лента содержит и **неразобранные** события (`isPending`): подпись «Не разобрано», анализ — только по клику
    (так решила команда: автоматический анализ тратит бюджет). Во вкладках «Риски»/«Возможности» и в счётчиках
    неразобранные не учитываются;
  - «Разобрать новость» включена: ссылка **или** вставленный текст (первая строка — заголовок) → переход на карточку;
  - «Сначала проверьте» и «Точность персонализации» в API-режиме строятся из данных (`checklist`, пропуски профиля);
    в демо-режиме — прежние тексты.
- **`BusinessInsightCard.tsx`** — ссылка передаёт `?company=` (нужна для запуска анализа); у неразобранных
  событий кнопка «Запустить анализ» вместо «Подробнее».
- **`InsightDetailsPage.tsx`** — та же разметка, данные из инсайта:
  - для `/insights/event-<id>?company=...` запускается анализ (10–60 с, без автоповтора), затем адрес
    заменяется на адрес готового инсайта;
  - заголовок, отрасль/категория, статус проверки, главный эффект, цепочка влияния (`mechanismSteps`),
    «Что произошло» со ссылкой на первоисточник, «Почему это важно», новый блок «Риски и возможности»;
  - «Мнение банка»: тезисы `bankView` со ссылкой на PDF и страницу или «позиция не установлена»;
  - чат: история с сервера, ответы с бейджами `basis` (`EvidenceBadge`), предложенные уточнения;
  - «Следующий шаг» и чек-лист — из `next_steps`; «Основания вывода» — реальные доказательства со ссылками;
    «Что пока неизвестно» — `unknowns` и замечания проверки;
  - «Полезен ли анализ?» отправляет отзыв на сервер;
  - блок «Ход анализа» (`AnalysisTrace`).

## Действия пользователя и профиль (PR #14–#17)
- **Дисклеймер** (`Disclaimer.tsx`) — внизу ленты и карточки, пометка в блоке «Мнение банка».
- **Карточка ленты** — «Релевантность N/100», «Почему в ленте», число источников события, кнопка «Скрыть».
- **Шапка ленты** — «Финансовый директор ˅» стал выбором роли (`role.ts`, хранится в localStorage);
  роль уходит в чат уточнений.
- **«Профиль компании ↗» и «Дополнить профиль»** открывают `CompanyProfilePanel`: данные банка, выручка
  группы, связанные компании (группа / гипотеза), отрасли контрагентов, пропуски и форма «Дополнить профиль».
- **Карточка анализа** — «Источники события (N)», кнопки «Задать вопрос аналитику банка» и «Связаться
  с менеджером»; если чат ответил «в данных нет сведений», появляется подсказка передать вопрос аналитику.
- API-вызовы — `features/insights/userActions.ts`.

## Новость от пользователя (ветка `ai/user-news`) — не обязательно
- В событии появились поля `content` (`full` / `partial` / `title_only` / `null`) и `submitted_by` (id компании или `null`).
- Можно показать у разбора значок «по заголовку» (`title_only`) или «фрагмент» (`partial`). Пояснение уже приходит
  в `quality_issues`, статус в этих случаях — `partial`.
- Ошибка загрузки ссылки приходит как HTTP 400 с понятным текстом в `detail` («…вставьте текст вручную»). Стоит
  показать его как есть и предложить вставить текст.
