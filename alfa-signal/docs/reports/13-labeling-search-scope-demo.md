# Отчёт 13. Разметка, поиск по аналитике банка, изоляция компаний, демо без ключа

## Разметка
`scripts/make_labeling_set.py` — таблицы «событие × компания» для разметчиков из реальной базы (разные компании,
события поровну по типам, общие пары для согласия, скрытый ключ с оценками системы, инструкция со шкалой 0–3).
`scripts/score_labels.py` — согласие людей (точное, ±1, взвешенная каппа), P@5, Recall@5, nDCG@5, порог ленты,
худшие ошибки. Порядок работы — `docs/labeling.md`.

## Поиск по аналитике банка
Аудит: старый прогноз ставки выше свежего, «рынок труда» — старый обзор, единственный документ о стали не в топ-3.
Причины: штраф ×0,5 документам старше года прятал единственный профильный документ; темы документов из реестра
не использовались; «потребительский» и «потребление» не сопоставлялись. Исправлено: темы (×1,35), однокоренные
слова, свежесть по теме вместо абсолютного штрафа. Контрольные вопросы (14): первым нужный документ — 64% → 100%,
в топ-3 — 86% → 100% (`scripts/eval_bank_search.py`; веса подбирались на этих вопросах — добавляйте новые).

## Изоляция компаний
`API_REQUIRE_COMPANY_SCOPE=1`: без `X-Company-Id` — 401, с чужим — 403, в том числе на эндпоинтах компании, где
проверки не было; список компаний — только `DEMO_COMPANY_IDS`. Фронтенд передаёт заголовок в каждом запросе.

## Демо без ключа LLM
`scripts/export_demo.py` выгружает события, готовые разборы, журналы и ролевые блоки; `seed_demo.py` загружает
снимок в чистую базу. В `data/demo/` (попадает в git) — только синтетические компании: скрипт не даст положить туда
реальные без `--allow-real`.
