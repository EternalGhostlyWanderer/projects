# Отчёт 3. Объяснимый скоринг релевантности 0–100

## Зачем
Задача P0: балл 0–100, разложенный на понятные факторы; лента сортируется по баллу; сумма факторов
равна баллу; нерелевантное — 0; не завышать за похожие факторы; одна новость — разные баллы для
разных компаний. Раньше лента сортировалась по числу совпавших признаков, без весов и объяснения.

## Что сделано
- `backend/app/modules/personalization/scoring.py` — пять групп (отрасль, финансовые каналы,
  география, цепочка поставок, связанные компании), максимум внутри группы, значимость события,
  правила против нерелевантного (отраслевые события, страны, порог показа 10). Описание — `docs/scoring.md`.
- `assess_relevance` возвращает прежние поля и новые: `score`, `level`, `components`, `explanation`.
- Лента: сортировка по баллу, фильтр по порогу; агент видит балл в `assess_relevance`; балл и уровень
  в анализе равны баллу ленты, причины релевантности модель строит по разложению.
- Извлечение событий по ключевым словам теперь находит страны (Китай, Турция, Казахстан…, юань → Китай).
- `run_eval.py`: Recall@5 и сравнение с прежним ранжированием; `demo_scenario.py` печатает балл и объяснение.
- Карточка ленты: «Релевантность N/100», «Почему в ленте», разложение во всплывающей подсказке,
  число источников события после склейки.

## Проверка
- 10 тестов (`tests/test_scoring.py`): сумма факторов = балл и 0–100; нерелевантное = 0; три похожих
  продукта не утраивают балл; одна новость — разные баллы; отраслевое событие не попадает каждому
  заёмщику; страна должна совпадать; цепочка поставок — гипотеза пропорционально доле; малая доля
  поставок не показывается; компания группы учитывается; уровни. Всего 116 тестов backend.
- Синтетика: Precision@5 0,71 → 0,80 при той же полноте 0,945. Первые версии правил давали хуже
  (каждому заёмщику попадали отраслевые новости о льготных кредитах, торгующим с Турцией — новости о
  платежах в Китай); это найдено на прогоне и исправлено правилами выше.

## Ограничения и что дальше
- Веса подобраны экспертно и проверены на синтетике; для реальных компаний нужна разметка
  (задача P1) — после неё веса стоит перепроверить.
- Отрасли события при извлечении по ключевым словам покрывают 8 групп; извлечение через LLM точнее.
