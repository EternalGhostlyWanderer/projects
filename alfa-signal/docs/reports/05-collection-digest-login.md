# Отчёт 5. Сбор по расписанию, предварительный анализ, сводка, демо-вход

## Зачем
- Новости должны подхватываться регулярно, а не только по клику (ваш запрос; вебинар, вопросы 36, 60).
- Важное должно открываться мгновенно, но без анализа каждой новости для каждой компании — бюджет 500 ₽ в день.
- Нужна сводка дня или недели (60) и демонстрационная авторизация для жюри (63).
- Для подбора весов скоринга нужна сводка по данным организаторов без раскрытия строк.

## Что сделано
- `backend/app/modules/news/scheduler.py` — сбор RSS по расписанию (`NEWS_COLLECT_INTERVAL_MIN`, по умолчанию
  выключен) и по кнопке; предварительный анализ 1–2 самых важных событий на компанию с порогом балла,
  суточным лимитом и остановкой при исчерпании бюджета LLM; состояние — в `/system/status`.
- `POST /api/v1/events/refresh` — «Обновить ленту» (в фоне); `GET /api/v1/feed/digest` — сводка за период.
- Интерфейс: «Главное за сутки», кнопка обновления ленты с реальным временем обновления (было «09:40» текстом).
- Демо-вход: `POST /api/v1/auth/login`, экран входа (`VITE_DEMO_AUTH=1`), компании пользователя из `DEMO_USERS`,
  выход по аватару. По умолчанию demo / alfa-signal.
- `scripts/profile_data.py` — обезличенная сводка по данным организаторов: типы клиентов, заглушки выручки,
  крупный бизнес по группам, заполненность ФТС и страны, продукты, топ отраслей, связи через физлиц,
  доля переводов себе и доля платежей между компаниями с профилем.
- Примеры RSS-лент и настройки — в `backend/.env.example`; описание — `docs/news-collection.md`.

## Проверка
- 9 новых тестов (`tests/test_scheduler.py`): предварительный анализ берёт события с баллом ≥ 30 и пропускает
  остальные, не трогает разобранные и скрытые, соблюдает лимит и останавливается при исчерпании бюджета,
  суточный счётчик, планировщик выключен по умолчанию, сводка за сутки и неделю отсортирована по баллу,
  эндпоинт обновления, демо-вход (по умолчанию и с компаниями). Всего 133 теста backend.
- Фронтенд: `tsc -b`, eslint, prettier.
- Playwright на синтетике: неверный пароль — ошибка, верный — лента; «Главное за сутки» показывает свежую
  новость про ставку; «Обновить ленту» запускает сбор (без `NEWS_RSS_URLS` — понятное сообщение в статусе);
  выход возвращает на экран входа; ошибок в консоли нет.

## Ограничения
- Из облачного окружения новостные сайты недоступны, поэтому RSS-ленты по умолчанию не проверены —
  проверьте их из своей сети (`load_events.py --rss <url>`).
- GDELT (`modules/news/sources/api.py`, участник 2) в планировщик не подключён: по опыту Марии он часто
  отвечает «слишком много запросов» и требует VPN.
