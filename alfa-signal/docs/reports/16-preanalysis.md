# Отчёт 16. Предварительный анализ при открытии ленты

## Зачем
После #27 предварительный анализ был выключен по умолчанию, и разбор начинался только по клику: страница «думала»
полминуты на каждую карточку. Решение команды: разбирать заранее, но немного — 3–5 самых важных событий, быстро.

## Что сделано
- Открытие ленты запускает фоновый разбор до 5 верхних неразобранных событий (балл от 30) — по 2 одновременно,
  самые важные первыми; затем ролевой блок для роли пользователя. Лента не ждёт.
- Повторное открытие во время разбора ничего не запускает; уже разобранные события пропускаются; лимит 40 в день;
  остановка при исчерпании бюджета LLM.
- Ответ ленты: `preanalysis` и `preparing` у карточек; фронтенд — «Готовится разбор…» и обновление каждые 10 секунд,
  пока разбор идёт.
- По умолчанию включено (`PREANALYZE_ACTIVE=1`) в `.env.example` и `docker-compose.yml`.

## Проверка
`tests/test_scheduler.py`: 5 событий из 8, не больше 2 одновременно, повторный запрос не запускает разбор, ролевой
блок для каждого разбора, дневной лимит, остановка по бюджету. Всего 235 OK; frontend `npm run check` OK.
