# Сведения о компании от пользователя и из его документов

## Зачем
Данных банка (отрасль, продукты, ФТС, платежи) мало, чтобы понять, что компании действительно важно. Вебинар
(вопросы 28 и 33) допускает сведения от пользователя. Пользователь может заполнить их вручную или загрузить
документ — договор, отчётность, описание компании, — и сервис сам найдёт в нём нужное.

## Поля (`app/modules/companies/user_data.py`)
| Поле | Где учитывается |
|---|---|
| долг с плавающей и фиксированной ставкой | лента (ставка), расчёт в чате, доказательства |
| валюты контрактов, валюты выручки | лента (курс) |
| страны поставщиков и покупателей | лента (внешняя торговля, география) |
| доля экспорта в выручке | лента: курс и внешняя торговля при экспорте от 10% |
| отрасли покупателей и поставщиков | лента: цепочка поставок для отраслевых событий |
| основные закупки, планы инвестиций и заимствований, ковенанты | доказательства разбора |
| **темы, важные компании** («курс юаня», «пошлины на металл») | лента: группа «Интересы компании», до 15 баллов, если все основные слова темы есть в событии |

У каждого поля хранится источник (`field_sources`): вручную или из документа — с названием документа, цитатой,
датой и пользователем. В доказательствах: «Со слов пользователя: …» или «Из документа пользователя «…»: …».

## Сценарий «из документа»
1. Пользователь вставляет текст или загружает файл (TXT, MD, CSV, JSON, PDF до 8 МБ; Word — вставить текст).
2. `POST /api/v1/companies/{id}/user-data/extract` — модель из разрешённого списка (роль `extract`, по умолчанию
   Gemma) находит поля и к каждому даёт дословную цитату. Код проверяет, что цитата есть в документе, поле —
   из списка, значение — проходит проверку модели данных (например, доля не больше 100%). Неподходящие поля —
   в `rejected`. **Ничего не сохраняется.**
3. Пользователь видит поля с цитатами, снимает лишние галочки и сохраняет:
   `POST /api/v1/companies/{id}/user-data/apply-document`.
4. Лента пересчитывается сразу (балл без LLM), следующие разборы учитывают новые сведения.

## Безопасность
- Текст документа — данные: в промпте явно сказано игнорировать инструкции внутри него.
- Документ не хранится; хранятся только подтверждённые поля, цитаты до 400 символов и журнал.
- Журнал изменений `GET /api/v1/companies/{id}/user-data/history`: кто, когда, какие поля, вручную или из
  документа (без значений).
- В интерфейсе предупреждение: не загружать персональные данные.
- Ограничения размера: 60 тыс. символов текста, 8 МБ файла.
