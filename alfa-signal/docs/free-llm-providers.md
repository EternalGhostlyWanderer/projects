# Бесплатные LLM-провайдеры

Ключ шлюза организаторов (`changellenge.up.railway.app`) истёк вместе с хакатоном. Клиент
(`backend/app/llm/client.py`) работает через OpenAI SDK, поэтому подходит любой OpenAI-совместимый API.
Провайдер выбирается одной переменной `LLM_PROVIDER`. Адрес, модель и способ отключения рассуждений берутся
из пресета в `backend/app/llm/config.py`, а `LLM_BASE_URL`, `LLM_MODEL` и `LLM_THINK_STYLE` их переопределяют.

> Бесплатные лимиты и списки моделей у провайдеров часто меняются. Значения ниже актуальны на октябрь 2026,
> перед использованием сверьтесь со страницей лимитов провайдера.

| `LLM_PROVIDER` | Где взять ключ | Модель по умолчанию | Бесплатный лимит (примерно) | Комментарий |
|---|---|---|---|---|
| `openrouter` | [openrouter.ai/keys](https://openrouter.ai/keys) | `openrouter/free` | 20 запросов/мин, 50/день; 1000/день после разового пополнения на $10 | Один ключ на десятки бесплатных моделей с суффиксом `:free`. Иногда среди них есть модели из списка хакатона (Gemma, Qwen, DeepSeek, GLM, Kimi) |
| `groq` | [console.groq.com/keys](https://console.groq.com/keys) | `qwen/qwen3.8-27b` | ~30 запросов/мин, дневной лимит по токенам | Очень быстрый, без карты. Есть также Qwen3 и gpt-oss |
| `gemini` | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | `gemini-flash-lite-latest` | сотни–1500 запросов/день на Flash | Самый щедрый лимит, хорошо пишет по-русски, понимает изображения. Вне ЕС запросы бесплатного плана могут использоваться для обучения. Из РФ нужен доступ к сервису |
| `deepseek` | [platform.deepseek.com](https://platform.deepseek.com/api_keys) | `deepseek-chat` | платный, оплата по факту (дёшево) | Бесплатного тарифа нет; бесплатно DeepSeek можно получить через OpenRouter — модели `deepseek/...:free` |
| `mistral` | [console.mistral.ai](https://console.mistral.ai) | `mistral-small-latest` | план Experiment: лимит запросов в минуту и в день | Нужно подтвердить телефон |
| `ollama` | ключ не нужен | `qwen3:14b` | без лимитов, всё работает на вашем компьютере | `ollama pull qwen3:14b`. Нужно около 10 ГБ памяти, слабее облачных моделей |
| `hackathon` | ключ команды | `qwen/qwen3.6-35b-a3b` | — | Шлюз организаторов, для истории |

Другие OpenAI-совместимые сервисы с бесплатным доступом (Cerebras, SambaNova, NVIDIA NIM, Cloudflare Workers AI,
GitHub Models) подключаются так же. Возьмите любой пресет и задайте `LLM_BASE_URL`, `LLM_MODEL` и
`LLM_THINK_STYLE=none`.

## Запасные нейросети (`LLM_FALLBACKS`)

Бесплатные модели отключают без предупреждения: так в октябре 2026 Google закрыл `gemini-2.5-flash` для
новых ключей, и все разборы вернули ошибку 404. Поэтому можно перечислить запасные маршруты. Если
основная модель не ответила, запрос уходит следующей по списку.

```env
LLM_PROVIDER=gemini
LLM_API_KEY=AIza...
LLM_FALLBACKS=gemini:gemini-3.1-flash-lite,gemini:gemma-4-31b-it,groq:qwen/qwen3.8-27b,gemini:gemma-4-26b-a4b-it,groq:openai/gpt-oss-120b,openrouter:nvidia/nemotron-3-ultra-550b-a55b:free,gemini:gemini-3.8-flash,deepseek
GROQ_API_KEY=gsk_...
OPENROUTER_API_KEY=sk-or-...
DEEPSEEK_API_KEY=sk-...
```

- Элемент списка — `провайдер` или `провайдер:модель`. Без модели берётся модель пресета.
  У бесплатного ключа Gemini дневной лимит считается отдельно для каждой модели: у `gemini-3.8-flash` —
  20 запросов в сутки (октябрь 2026), у Flash-Lite и Gemma — заметно больше; актуальные цифры —
  [ai.dev/rate-limit](https://ai.dev/rate-limit). Поэтому основная модель по умолчанию —
  `gemini-flash-lite-latest` (псевдоним на актуальную Flash-Lite), а в запасных сначала
  `gemma-4-26b-a4b-it` (та же Gemma 4, что была в списке хакатона; системную инструкцию сервис переносит
  в сообщение сам), затем `gemini-3.8-flash` как небольшой запас.
- Модель OpenRouter можно указать явно, например бесплатную DeepSeek:
  `openrouter:deepseek/<модель>:free` (актуальные имена — на
  [openrouter.ai/models?q=deepseek&max_price=0](https://openrouter.ai/models?q=deepseek&max_price=0)).
- Ключ запасного провайдера берётся из `<ПРОВАЙДЕР>_API_KEY`. Для того же провайдера, что основной,
  используется `LLM_API_KEY`. Провайдер без ключа пропускается и запуск не ломает. Ollama ключ не нужен,
  адрес задаётся в `OLLAMA_BASE_URL`.
- **На запасной маршрут** запрос переходит при отключённой модели (404), непринятом ключе, исчерпанном
  лимите провайдера, ответе 429, сбое сети или 5xx и пустом ответе. Сбойный маршрут ставится на паузу:
  на час, если дело в настройке или дневном лимите, и на минуту при временном сбое. Остальные запросы
  в это время сразу идут запасному.
- **Свой дневной лимит** (`LLM_DAILY_REQUEST_LIMIT`) общий для всех маршрутов. Его исчерпание запасные
  маршруты не тратит.
- Если провайдер отвергает параметр отключения рассуждений или JSON-режим (ошибка 400), запрос
  повторяется без этого параметра, и для этого маршрута он больше не отправляется.
- Проверить все маршруты сразу:
  `docker compose exec backend python scripts/check_llm.py`.
  Флаг `--models` покажет модели, доступные по ключу.

## Рекомендация

1. **Gemini** (`LLM_PROVIDER=gemini`): лучший баланс качества и лимита для разборов на русском.
2. **OpenRouter** — запасной вариант. Чтобы остаться близко к моделям хакатона, укажите конкретную бесплатную
   модель, например `LLM_MODEL=qwen/...:free` (актуальный список:
   [openrouter.ai/models?max_price=0](https://openrouter.ai/models?max_price=0)).
   Держите `LLM_DAILY_REQUEST_LIMIT` ниже 50, иначе после лимита придут ошибки 429.
3. **Ollama** — если нужен офлайн-режим или нельзя отправлять данные во внешний сервис.

Один разбор агента — 1–3 запроса к LLM: план, анализ и иногда исправление по замечаниям проверки, плюс
ролевой блок. Как уложиться в бесплатный лимит:
- `AGENT_LLM_PLAN=0` — план по правилам вместо запроса к модели. Обязательные шаги и сверка с прогнозами
  банка добавляются политикой агента в любом случае;
- `ROLE_VIEW_LLM=0` — ролевой блок по правилам;
- `PREANALYZE_PER_COMPANY` и `PREANALYZE_DAILY_LIMIT` — сколько событий разбирать заранее.

Что экономится автоматически:
- в запрос не уходят пустые поля, отступы и служебные `title` из JSON Schema;
- текст новости передаётся один раз, длинные фрагменты обрезаются;
- в чат и ролевой блок не уходят служебные поля разбора;
- план агента зависит только от события, поэтому для других компаний он берётся из кеша. Итог — примерно
  на 14% меньше токенов на разбор.

Повторные запросы берутся из кеша (`backend/var/llm.sqlite3`) и лимит не тратят. На ответ 429 по минутному
лимиту клиент ждёт и повторяет запрос (до 3 раз), дневной лимит останавливает фоновый разбор.

## Примеры `.env`

```env
# Google Gemini
LLM_PROVIDER=gemini
LLM_API_KEY=AIza...
```

```env
# OpenRouter, конкретная бесплатная модель; разные модели по ролям
LLM_PROVIDER=openrouter
LLM_API_KEY=sk-or-...
LLM_MODEL=openrouter/free
# LLM_MODEL_EXTRACT=<лёгкая модель>:free
LLM_DAILY_REQUEST_LIMIT=45
```

```env
# Ollama на хосте, backend в Docker
LLM_PROVIDER=ollama
LLM_BASE_URL=http://host.docker.internal:11434/v1
LLM_MODEL=qwen3:14b
```

## Если модель отвечает с ошибками

- **400 из-за неизвестного параметра** — поставьте `LLM_THINK_STYLE=none`.
- **Модель не умеет `response_format`** — поставьте `LLM_JSON_MODE=0`. Клиент сам достанет JSON из текста
  и попросит модель исправить ответ, если тот не прошёл схему.
- **Ответ обрывается** — выберите модель с большим контекстом или уберите режим рассуждений.
- **Проверка подключения:** `cd backend && python scripts/test_connection.py`.
