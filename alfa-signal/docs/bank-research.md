# Аналитика Альфа-Банка: индекс и поиск

Модуль `backend/app/research/` превращает PDF Центра макроэкономического анализа
в фрагменты с документом, датой и страницей и ищет по ним. Найденные фрагменты
становятся доказательствами `BANK_ANALYSIS` в инсайте; если ничего не найдено,
`bank_view.status = "not_found"` и позиция банка не выдумывается.

## Особенность материалов
Все PDF из кейса — **сканы без текстового слоя** (каждая страница — картинка).
Поэтому страницы читаются в таком порядке:

1. текстовый слой PDF, если он есть;
2. ручная расшифровка `data/raw/bank_manual/<doc_id>/p<N>.txt` (абзацы через пустую строку) —
   ей можно заменить или поправить любую страницу;
3. распознавание через разрешённую модель `qwen/qwen3-vl-30b-a3b-instruct`
   (роль `vision`), один запрос на страницу.

Результат по каждому документу сохраняется в `data/processed/bank_pages/<doc_id>.json`
и повторно не распознаётся. Папка `data/` не попадает в Git.

## Как собрать индекс

1. Положите PDF в `data/raw/` — можно в любую подпапку, как остальные данные (имена можно не менять — документ узнаётся по фрагменту имени,
   см. `file_hints` в `backend/app/research/registry.py`).
2. Бесплатная проверка — какие файлы узнаны и сколько страниц надо распознать:
   ```
   python backend/scripts/build_bank_index.py
   ```
3. Проба на одной странице (1 платный запрос) — убедиться, что шлюз принимает изображения:
   ```
   python backend/scripts/build_bank_index.py --vision --max-pages 1 --doc policy_rate_2026_09_11
   ```
   Посмотрите `data/processed/bank_pages/policy_rate_2026_09_11.json`: текст должен совпадать со сканом.
4. Распознать всё (около 37 страниц без FI Strategy; скрипт покажет число и спросит `yes`):
   ```
   python backend/scripts/build_bank_index.py --vision
   ```
5. Поиск без API:
   ```
   python backend/scripts/search_bank.py "ЦБ сохранил ключевую ставку" --channels interest_rate
   ```

Пересобрать один документ: `--doc <doc_id>`; всё заново: `--force`.

## Графики и таблицы
- Модель распознавания описывает график отдельным блоком `chart`: название, оси, единицы, период,
  направление динамики и только **подписанные** значения (без оценки «на глаз» по линиям).
- В индексе такой фрагмент помечен «График (распознан с изображения, значения приблизительные)»,
  чтобы агент не выдавал прочитанные с картинки числа за точные.
- Основные тезисы банка почти всегда продублированы в тексте рядом с графиком — поиск в первую
  очередь находит их. Проверить распознавание графиков: страница 1 «Бонд Бриф» (два графика):
  `python backend/scripts/build_bank_index.py --vision --max-pages 1 --doc bond_brief_2026_09_14`.
- Если график распознан плохо, поправьте страницу вручную: `data/raw/bank_manual/<doc_id>/p<N>.txt`
  (ручная расшифровка имеет приоритет над распознаванием).

## Как устроен поиск
- BM25 по русским словам с упрощённым стеммингом — без эмбеддингов и внешних сервисов.
- Каналы влияния события добавляют в запрос тематические слова и повышают документы
  той же темы (`channels` в реестре).
- Документы старше года (обзор стали 2021 г.) получают штраф и помечаются `stale`.
- Не больше 3 фрагментов из одного документа; фрагмент засчитывается, только если
  в нём есть хотя бы 2 слова запроса — иначе материалов «не найдено».

## Прогнозы банка и их пересмотры
Обзоры повторяют таблицу прогнозов, но цифры меняются от выпуска к выпуску. При сборке индекса
(`build_bank_index.py`) прогнозы извлекаются из таблиц со столбцами «2026П», «2027П» и сохраняются
в `bank_index.json` → `forecasts`. Для каждого показателя актуален самый свежий документ, расхождение
со старыми помечается как пересмотр (`backend/app/research/forecasts.py`).

Найдено в материалах кейса (40 прогнозов из 3 обзоров):

| Показатель | Было | Стало |
|---|---|---|
| ключевая ставка на конец 2026 | 13,5% (31.07, 07.09) | **14,0%** (11.09) |
| средняя ставка за 2026 | 14,5% | **14,6%** |
| средняя ставка за 2027 | 12,6% → 12,5% | **13,0%** |
| курс доллара на конец 2027 | 95,0 | **93,0** |

Агент получает актуальные прогнозы инструментом `get_bank_forecasts`; вывод, который выдаёт прежний
прогноз за текущий, не проходит проверку (`outdated_bank_forecast`). В поиске свежие обзоры получают
небольшое преимущество (до 30 дней — вес 1,0, к 180 дням — 0,85), документы старше года — штраф 0,5.

После обновления кода индекс нужно пересобрать (без LLM): `python backend/scripts/build_bank_index.py`.

## Свежесть по теме и контрольные вопросы
Поиск (`app/research/search.py`):
- **темы документов** из реестра (`registry.py`: `topics` и название) — запрос совпал с темой → ×1,35;
- **однокоренные слова** с разными основами («потребительский» — «потребление»): общее начало от 6 букв, вес 0,7;
- **свежесть по теме**: если по той же теме (по реестру) есть документ новее, старые документы теряют 1% за
  каждые два дня разницы, не ниже 0,6. Июльский прогноз ставки уступает сентябрьскому, а единственный документ
  о стали (2021) не прячется: более свежего по теме нет. Абсолютный штраф за возраст больше года убран —
  возраст виден в поле `stale`.

Контрольные вопросы — `data/synthetic/bank_search_questions.json`, проверка — `python backend/scripts/eval_bank_search.py`.
На материалах кейса: нужный документ первым — 64% → 100%, в топ-3 — 86% → 100%. Веса подбирались на этих же
вопросах; для честной оценки добавляйте новые вопросы и смотрите, держится ли результат.
