# Результаты тестирования

Заполняется после запуска на целевой машине:

```sh
make clean
make
make test
sh tests/make_report_examples.sh
```

| Показатель | Значение |
|---|---|
| Дата и среда запуска | _впишите_ |
| Компилятор и флаги | `-std=c11 -O2 -Wall -Wextra -Wpedantic` (предупреждения: _впишите_) |
| `make test`: успешно / ошибок | _впишите_ / _впишите_ |
| Число повторных запусков подряд | _впишите_ |
| Нестабильные проверки | _впишите, если были (ожидание/обход на 4x4 зависят от расписания потоков)_ |

Выводы характерных запусков находятся в `test-results/examples/`.
